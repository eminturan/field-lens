# Field Lens

Azure DevOps Server 2022 extension (Boards hub). Lists work items of one type whose chosen Date/Time field falls in a date range and whose state is in a selected set; user-picked columns; CSV export.

```bash
npm install
npm test          # unit tests
npm run dev       # http://localhost:3003/hub/hub.html with mock data
npm run package   # out/turanemin.field-lens-<version>.vsix
```

Bump `version` in `package.json` and `vss-extension.json` before every package.
